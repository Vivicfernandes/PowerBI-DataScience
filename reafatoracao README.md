## 📌 **Sobre o Projeto**  

> **Objetivo:** Este repositório contém os materiais e exercícios práticos do curso **Microsoft Power BI para Data Science**. Ele demonstra como o **Power BI** pode ser usado para análise e visualização de dados em diferentes contextos, utilizando também **Jupyter Notebooks** e **R** para manipulação e tratamento de dados.  

### 🎯 **Principais Metas**  

✔️ Ensinar conceitos fundamentais do Power BI para análise de dados.  
✔️ Demonstrar o uso do Jupyter Notebook para ciência de dados.  
✔️ Aplicar linguagem R na análise de dados e integração com Power BI.  
✔️ Criar dashboards interativos para tomada de decisão baseada em dados.
